    Section 8.5 Writing Equations of Rational Functions

    In earlier sections, we used rational equations to identify domain restrictions, intercepts, holes, and asymptotes. We now reverse that process. Starting with a list of graphical features, we construct a rational function whose numerator and denominator produce those features.
    🔗
    The central idea is that factors have different roles depending on where they appear. A factor in the numerator can create an x-intercept. A factor in the denominator can create a vertical asymptote. A common factor in both the numerator and denominator can create a hole.
    🔗

    Subsection 8.5.1 Connecting Graphical Features to Factors

    • An x-intercept at \(x=r\) is created by a factor \((x-r)\) in the numerator that does not cancel.
      🔗
      🔗
    • A vertical asymptote at \(x=r\) is created by a factor \((x-r)\) in the denominator that does not cancel.
      🔗
      🔗
    • A hole at \(x=r\) is created by a common factor \((x-r)\) in both the numerator and denominator.
      🔗
      🔗
    These rules describe the location of each feature. An additional constant factor, usually called \(a\text{,}\) controls the vertical scale of the graph and is determined from another point.
    🔗

    Example 8.5.1. Building a Function from Three Features.

    Write the general form of a rational function with an x-intercept at \(x=-2\text{,}\) a vertical asymptote at \(x=3\text{,}\) and a hole at \(x=5\text{.}\)
    🔗
    Solution.
    The x-intercept requires \((x+2)\) in the numerator. The vertical asymptote requires \((x-3)\) in the denominator. The hole requires \((x-5)\) in both the numerator and denominator.
    🔗
    A general form is
    🔗
    \begin{equation*} f(x)=\frac{a(x+2)(x-5)}{(x-3)(x-5)}, \end{equation*}
    where \(a\ne0\text{.}\)
    🔗
    🔗
    🔗
    This example shows why, when graphing a function, you should first identify places where the function is undefined or indeterminate (e.g., where there is a hole). Then you can cancel the common factor to help you graph the function.
    🔗
    🔗

    Subsection 8.5.2 Domain Restrictions Remain Important

    Every zero of the original denominator is excluded from the domain, including a value whose factor later cancels. A canceled factor changes the type of discontinuity, but it does not restore the missing input to the domain.
    🔗

    Example 8.5.2. Factoring Before Interpreting the Domain.

    Analyze the domain and discontinuities of
    🔗
    \begin{equation*} g(x)=\frac{x^2+2x-3}{(x+1)(x-1)}. \end{equation*}
    Solution.
    Factor the numerator:
    🔗
    \begin{equation*} x^2+2x-3=(x+3)(x-1). \end{equation*}
    Thus,
    🔗
    \begin{equation*} g(x)=\frac{(x+3)(x-1)}{(x+1)(x-1)}. \end{equation*}
    The original denominator is zero at \(x=-1\) and \(x=1\text{,}\) so both values are excluded from the domain.
    🔗
    The factor \((x-1)\) cancels, so \(x=1\) produces a hole. The factor \((x+1)\) remains in the denominator, so \(x=-1\) produces a vertical asymptote.
    🔗
    🔗
    🔗
    This example illustrates the difference between an excluded input and a vertical asymptote. Every denominator zero is excluded, but only a noncanceled denominator factor creates a vertical asymptote.
    🔗
    🔗

    Subsection 8.5.3 Adding a New Graphical Feature

    Once the role of each factor is understood, a rational function can be modified deliberately. To add a vertical asymptote, place a new noncanceling factor in the denominator. To add an x-intercept, place a new noncanceling factor in the numerator. To add a hole, place the same new factor in both parts of the fraction.
    🔗

    Example 8.5.3. Adding a Vertical Asymptote.

    Modify
    🔗
    \begin{equation*} f(x)=\frac{(x+3)(x-1)}{(x+1)(x-1)} \end{equation*}
    so that the new function also has a vertical asymptote at \(x=0\text{.}\)
    🔗
    Solution.
    A vertical asymptote at \(x=0\) requires a noncanceling factor of \(x\) in the denominator. One suitable function is
    🔗
    \begin{equation*} F(x)=\frac{(x+3)(x-1)}{x(x+1)(x-1)}. \end{equation*}
    The common factor \((x-1)\) still creates a hole at \(x=1\text{.}\) The factors \(x\) and \((x+1)\) remain in the denominator, so the vertical asymptotes are \(x=0\) and \(x=-1\text{.}\)
    🔗
    🔗
    🔗
    This example shows that adding one factor can change both the degree comparison and the long-run behavior. After modifying a rational function, all features should be checked again rather than assuming the original features are the only ones affected.
    🔗
    🔗

    Subsection 8.5.4 Determining the Scale Factor

    The factors determine the locations of intercepts, holes, and vertical asymptotes, but they do not usually determine one unique function. A nonzero constant \(a\) can multiply the numerator without changing those locations. An additional point on the graph is used to determine \(a\text{.}\)
    🔗
    1. Use each x-intercept to create a noncanceling numerator factor.
      🔗
      🔗
    2. Use each vertical asymptote to create a noncanceling denominator factor.
      🔗
      🔗
    3. Use each hole to create a common factor in the numerator and denominator.
      🔗
      🔗
    4. Include a nonzero scale factor \(a\text{.}\)
      🔗
      🔗
    5. Substitute another point on the graph and solve for \(a\text{.}\)
      🔗
      🔗
    6. Verify the domain, discontinuities, intercepts, and long-run behavior.
      🔗
      🔗

    Example 8.5.4. Writing a Rational Function from Features and a Point.

    Write a rational function with an x-intercept at \(x=1\text{,}\) a vertical asymptote at \(x=-2\text{,}\) a hole at \(x=4\text{,}\) and a y-intercept at \((0,3)\text{.}\)
    🔗
    Solution.
    The three features produce the form
    🔗
    \begin{equation*} f(x)=\frac{a(x-1)(x-4)}{(x+2)(x-4)}. \end{equation*}
    Use the point \((0,3)\text{:}\)
    🔗
    \begin{align*} 3&=\frac{a(0-1)(0-4)}{(0+2)(0-4)},\\ 3&=-\frac{a}{2},\\ a&=-6. \end{align*}
    Therefore, one suitable function is
    🔗
    \begin{equation*} f(x)=\frac{-6(x-1)(x-4)}{(x+2)(x-4)}. \end{equation*}
    🔗
    🔗
    This example demonstrates the complete construction process. The factors create the requested local features, while the additional point selects the correct vertical scale from the family of functions with those same features.
    🔗
    🔗

    Subsection 8.5.5 Finding the Coordinate of a Constructed Hole

    The common factor determines the x-coordinate of a hole, but the y-coordinate comes from the simplified function. The hole is located where the simplified graph would have been if the original domain had included that input.
    🔗

    Example 8.5.5. Locating the Hole.

    Find the coordinates of the hole in
    🔗
    \begin{equation*} f(x)=\frac{-6(x-1)(x-4)}{(x+2)(x-4)}. \end{equation*}
    Solution.
    Cancel the common factor while retaining the restriction \(x\ne4\text{:}\)
    🔗
    \begin{equation*} f(x)=\frac{-6(x-1)}{x+2},\qquad x\ne4. \end{equation*}
    Evaluate the simplified expression at \(x=4\text{:}\)
    🔗
    \begin{equation*} y=\frac{-6(4-1)}{4+2}=-3. \end{equation*}
    The hole is at \((4,-3)\text{.}\)
    🔗
    🔗
    🔗
    This example reinforces that the x-coordinate of a hole is read from the canceled factor, while its y-coordinate is calculated from the simplified expression.
    🔗
    🔗

    Subsection 8.5.6 Functions Can Share Some Features but Differ in Others

    Two rational functions can have the same hole and vertical asymptote while having different x-intercepts, hole coordinates, or horizontal asymptotes. Matching one or two features does not make two rational functions equivalent.
    🔗

    Example 8.5.6. Comparing Related Rational Functions.

    Compare
    🔗
    \begin{equation*} f(x)=\frac{3(x-1)(x-4)}{(x+2)(x-4)} \end{equation*}
    and
    🔗
    \begin{equation*} g(x)=\frac{(x+1)(x-4)}{2(x+2)(x-4)}. \end{equation*}
    Solution.
    Both functions have a common factor \((x-4)\text{,}\) so both have a hole at \(x=4\text{.}\) Both have the noncanceling denominator factor \((x+2)\text{,}\) so both have a vertical asymptote at \(x=-2\text{.}\)
    🔗
    The function \(f\) has an x-intercept at \(x=1\text{,}\) while \(g\) has an x-intercept at \(x=-1\text{.}\) Their leading-coefficient ratios also differ, so their horizontal asymptotes differ.
    🔗
    🔗
    🔗
    This comparison shows why a complete analysis is necessary. Local discontinuities may match even when the remaining graph behaves differently.
    🔗
    🔗
    Writing a rational equation requires translating each graphical feature into an algebraic factor. Noncanceling numerator factors create x-intercepts, noncanceling denominator factors create vertical asymptotes, and common factors create holes. An additional point determines the scale factor. After constructing the equation, checking the domain, hole coordinates, intercepts, and asymptotes confirms that the function has all of the intended features.
