    Section 3.1 Introduction to Function Composition

    In many situations, we apply multiple processes in sequence, where the output of one process becomes the input of the next. This idea is captured mathematically using function composition.
    🔗
    For example, imagine performing a sequence of steps—each step transforms an input into a new value. By chaining these steps together, we create a new function that represents the entire process.
    🔗

    Definition 3.1.1.

    Let \(f\) and \(g\) be functions. The composition of \(f\) with \(g\text{,}\) written \(f(g(x))\text{,}\) is a new function obtained by applying \(g\) first, and then applying \(f\) to the result.
    🔗

    Remark 3.1.2.

    The key idea of composition is:
    🔗
    The output of one function becomes the input of the next function.
    🔗
    🔗

    Example 3.1.3.

    Suppose we have four functions \(A\text{,}\) \(B\text{,}\) \(C\text{,}\) and \(D\text{.}\) A composition of these functions can be written as
    \begin{equation*} P(x) = D(C(B(A(x))))\text{.} \end{equation*}
    🔗

    Example 3.1.4.

    Let \(F = m(h)\) represent the temperature (in degrees Fahrenheit) \(h\) hours after midnight. Let \(B = a(F)\) represent the growth rate of a colony of bacteria at temperature \(F\text{.}\)
    🔗

    Example 3.1.5.

    Let \(A = g(s)\) represent the surface area (in cm2) of a cube with side length \(s\text{.}\) Let \(s = f(v)\) represent the side length of a cube with volume \(v\text{.}\)
    🔗

    Example 3.1.6.

    Let \(T = f(n)\) represent the total cost to rent an indoor pool for \(n\) people. Let \(D = g(T)\) represent the discounted cost after applying a seasonal discount.
    🔗

    Example 3.1.8.

    Let \(M = a(x)\) represent the number of miles that can be driven in \(x\) hours. Let \(G = b(M)\) represent the number of gallons of gas used to drive \(M\) miles.
    🔗

    Activity 3.1.1. Composing Functions.

    Work with a partner or small group.
    🔗
    • Find as many pairs of functions as possible that can be composed.
      🔗
    • Write each composition using proper function notation.
      🔗
    • Find examples of functions that cannot be composed, and explain why.
      🔗
    • Challenge: find three or more functions that can be composed in sequence.
      🔗
