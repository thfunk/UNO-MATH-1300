    Section 3.2 Vertical and Horizontal Shifts

    A transformation changes the graph of a function in a predictable way. In this section, we focus on vertical and horizontal shifts. These shifts move a graph without changing its basic shape.
    🔗

    Objectives: Learning Objectives

    1. Identify vertical and horizontal shifts from function notation.
      🔗
      🔗
    2. Describe how a shift changes every point on a graph.
      🔗
      🔗
    3. Graph shifted functions from a given graph.
      🔗
      🔗
    4. Determine the location of a transformed point.
      🔗
      🔗
    🔗

    Subsection 3.2.1 Vertical Shifts

    Definition 3.2.1. Vertical Shift.

    Let \(y=f(x)\) be a function and let \(d\) be a real number. The graph of \(y=f(x)+d\) is the graph of \(f\) shifted vertically.
    🔗
    • If \(d>0\text{,}\) the graph shifts up \(d\) units.
      🔗
      🔗
    • If \(d<0\text{,}\) the graph shifts down \(|d|\) units.
      🔗
      🔗
    🔗
    A vertical shift changes the output of the function. Each point \((x,y)\) on the original graph becomes \((x,y+d)\) on the shifted graph.
    🔗

    Example 3.2.2. Recognizing a Vertical Shift from a Graph.

    The graph of \(g\) has the same shape as the graph of \(f\text{,}\) but every point on \(g\) is 3 units above the corresponding point on \(f\text{.}\) Write \(g\) in terms of \(f\text{.}\)
    🔗
    Solution.
    Because each output is 3 larger, the shift is vertical and upward.
    🔗
    \begin{equation*} g(x)=f(x)+3 \end{equation*}
    🔗
    🔗

    Example 3.2.3. Tracking One Point Through a Vertical Shift.

    The point \((-2,5)\) is on the graph of \(f\text{.}\) What point is on the graph of \(p(x)=f(x)-7\text{?}\)
    🔗
    Solution.
    The expression \(f(x)-7\) shifts every point down 7 units. The input stays the same, and the output changes from \(5\) to \(5-7=-2\text{.}\)
    🔗
    The corresponding point is \((-2,-2)\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 3.2.2 Horizontal Shifts

    Definition 3.2.4. Horizontal Shift.

    Let \(y=f(x)\) be a function and let \(c\) be a real number. The graph of \(y=f(x-c)\) is the graph of \(f\) shifted horizontally.
    🔗
    • If \(c>0\text{,}\) the graph shifts right \(c\) units.
      🔗
      🔗
    • If \(c<0\text{,}\) then \(f(x-c)=f(x+|c|)\text{,}\) and the graph shifts left \(|c|\) units.
      🔗
      🔗
    🔗
    A horizontal shift changes the input location of each point. Each point \((x,y)\) on the original graph becomes \((x+c,y)\) on the graph of \(f(x-c)\text{.}\)
    🔗

    Warning 3.2.5.

    The direction of a horizontal shift may look opposite to the sign inside the parentheses. The graph of \(f(x-4)\) shifts right 4 units, while the graph of \(f(x+4)\) shifts left 4 units.
    🔗
    🔗

    Example 3.2.6. Recognizing a Horizontal Shift from a Graph.

    The graph of \(h\) has the same shape as the graph of \(f\text{,}\) but every point on \(h\) is 2 units to the left of the corresponding point on \(f\text{.}\) Write \(h\) in terms of \(f\text{.}\)
    🔗
    Solution.
    A shift left 2 units is produced by adding 2 to the input.
    🔗
    \begin{equation*} h(x)=f(x+2) \end{equation*}
    🔗
    🔗

    Example 3.2.7. Tracking One Point Through a Horizontal Shift.

    The point \((6,-1)\) is on the graph of \(f\text{.}\) What point is on the graph of \(q(x)=f(x-5)\text{?}\)
    🔗
    Solution.
    The graph shifts right 5 units. The input location changes from \(6\) to \(6+5=11\text{,}\) while the output remains \(-1\text{.}\)
    🔗
    The corresponding point is \((11,-1)\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 3.2.3 Combining Horizontal and Vertical Shifts

    A function of the form \(g(x)=f(x-c)+d\) combines a horizontal shift with a vertical shift. A point \((x,y)\) on the graph of \(f\) becomes \((x+c,y+d)\) on the graph of \(g\text{.}\)
    🔗

    Example 3.2.8. Tracking a Point Through Two Shifts.

    The point \((-1,4)\) is on the graph of \(f\text{.}\) Find the corresponding point on the graph of
    🔗
    \begin{equation*} g(x)=f(x+3)-6. \end{equation*}
    Solution.
    The expression \(x+3\) shifts the graph left 3 units, so the new input coordinate is \(-1-3=-4\text{.}\)
    🔗
    The value \(-6\) outside the function shifts the graph down 6 units, so the new output coordinate is \(4-6=-2\text{.}\)
    🔗
    The corresponding point is \((-4,-2)\text{.}\)
    🔗
    🔗
    🔗

    Example 3.2.9. Shifting an Entire Graph.

    Use the graph described above to sketch \(h(x)=f(x-2)+1\text{.}\) Describe the movement of the graph and state how each point changes.
    🔗
    Solution.
    The expression \(x-2\) shifts the graph right 2 units. The value \(+1\) outside the function shifts the graph up 1 unit.
    🔗
    Each point \((x,y)\) becomes \((x+2,y+1)\text{.}\) Open endpoints remain open, closed endpoints remain closed, and the shape of the graph does not change.
    🔗
    🔗
    🔗

    Example 3.2.10. Writing a Shifted Function.

    The graph of \(r\) is obtained by shifting the graph of \(f\) left 5 units and up 2 units. Write \(r\) in terms of \(f\text{.}\)
    🔗
    Solution.
    A shift left 5 units changes the input to \(x+5\text{.}\) A shift up 2 units adds 2 to the output.
    🔗
    \begin{equation*} r(x)=f(x+5)+2 \end{equation*}
    🔗
    🔗
    🔗

    Subsection 3.2.4 Exploring Shifts with Desmos

    A graphing tool can help you compare a function with its transformations. In the Desmos Graphing Calculator, enter a base function such as \(f(x)=|x|\text{.}\) On separate lines, graph examples such as \(f(x)+3\text{,}\) \(f(x)-2\text{,}\) \(f(x-4)\text{,}\) and \(f(x+1)\text{.}\)
    🔗

    Activity 3.2.1. Compare the Graphs.

    1. Open the Desmos Graphing Calculator.
      🔗
      🔗
    2. Enter \(f(x)=|x|\text{.}\)
      🔗
      🔗
    3. On new lines, enter \(f(x)+3\text{,}\) \(f(x)-2\text{,}\) \(f(x-4)\text{,}\) and \(f(x+1)\text{.}\)
      🔗
      🔗
    4. For each graph, describe the direction and distance of the shift.
      🔗
      🔗
    5. Choose one point on the original graph and verify where that point moves under each transformation.
      🔗
      🔗
    🔗
    🔗

    Subsection 3.2.5 Key Ideas

    • \(f(x)+d\) changes outputs and shifts the graph vertically.
      🔗
      🔗
    • \(f(x-c)\) changes input locations and shifts the graph horizontally.
      🔗
      🔗
    • For \(g(x)=f(x-c)+d\text{,}\) a point \((x,y)\) becomes \((x+c,y+d)\text{.}\)
      🔗
      🔗
    • Horizontal shift signs appear opposite the direction of movement: subtraction shifts right and addition shifts left.
      🔗
      🔗
