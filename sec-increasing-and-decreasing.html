    Section 1.5 Increasing and Decreasing Functions

    Functions can change in different ways as the input changes. One important question is whether the outputs get larger or smaller as we move from left to right across a graph.
    🔗

    Definition 1.5.1. Increasing Function.

    A function is increasing on an interval if the outputs become larger as the inputs become larger.
    🔗
    🔗

    Definition 1.5.2. Decreasing Function.

    A function is decreasing on an interval if the outputs become smaller as the inputs become larger.
    🔗
    🔗

    Remark 1.5.3.

    To determine whether a graph is increasing or decreasing, read the graph from left to right. If the graph rises, the function is increasing. If the graph falls, the function is decreasing.
    🔗
    🔗

    Subsection 1.5.1 Identifying Increasing and Decreasing Intervals from Graphs

    Example 1.5.4. A Function with One Turning Point.

    Determine the interval(s) on which the graph described above is increasing and decreasing.
    🔗
    Solution.
    The graph falls as we move toward x=3 from the left, so it is decreasing on \((-\infty,3)\text{.}\)
    🔗
    The graph rises after x=3, so it is increasing on \((3,\infty)\text{.}\)
    🔗
    🔗
    🔗

    Example 1.5.5. Multiple Increasing and Decreasing Intervals.

    Determine where the function is increasing and decreasing.
    🔗
    Solution.
    The graph rises until x=-2, decreases from x=-2 to x=4, and then rises again after x=4.
    🔗
    Increasing: \((-\infty,-2)\cup(4,\infty)\)
    🔗
    Decreasing: \((-2,4)\)
    🔗
    🔗
    🔗

    Example 1.5.6. Identifying Both Increasing and Decreasing Intervals.

    Use the graph described above to identify every interval on which the function is increasing and every interval on which the function is decreasing.
    🔗
    Solution.
    Read the graph from left to right. The graph rises until it reaches the local maximum at \(x=-3\text{,}\) so the function is increasing on \((-\infty,-3)\text{.}\)
    🔗
    The graph then falls from \(x=-3\) to the local minimum at \(x=2\text{,}\) so the function is decreasing on \((-3,2)\text{.}\)
    🔗
    After \(x=2\text{,}\) the graph rises again, so the function is increasing on \((2,\infty)\text{.}\)
    🔗
    Combining the two increasing intervals gives:
    🔗
    \begin{equation*} \text{Increasing on }(-\infty,-3)\cup(2,\infty). \end{equation*}
    \begin{equation*} \text{Decreasing on }(-3,2). \end{equation*}
    🔗
    🔗

    Example 1.5.7. Finding Decreasing Intervals.

    Identify all intervals on which the graph is decreasing.
    🔗
    Solution.
    The graph falls as x approaches 1, rises between x=1 and x=5, and falls again after x=5.
    🔗
    Decreasing: \((-\infty,1)\cup(5,\infty)\)
    🔗
    🔗
    🔗
    🔗

    Subsection 1.5.2 Identifying Increasing and Decreasing Behavior from Tables

    A table can also reveal whether a function is increasing or decreasing. Compare the outputs as the inputs increase.
    🔗

    Example 1.5.8. An Increasing Function.

    Is the function increasing or decreasing?
    🔗
    Solution.
    As the inputs increase from week 1 to week 4, every output increases. Therefore, the function is increasing.
    🔗
    🔗
    🔗

    Example 1.5.10. A Decreasing Function.

    Is the function increasing or decreasing?
    🔗
    Solution.
    As the inputs increase, the outputs continually decrease. Therefore, the function is decreasing.
    🔗
    🔗
    🔗

    Example 1.5.12. Neither Increasing nor Decreasing.

    Is the function increasing or decreasing?
    🔗
    Solution.
    The outputs increase, then decrease, then increase again. The function is neither increasing nor decreasing on its entire domain.
    🔗
    🔗
    🔗
    🔗

    Subsection 1.5.3 Key Ideas

    • Read graphs from left to right.
      🔗
      🔗
    • If outputs get larger as inputs get larger, the function is increasing.
      🔗
      🔗
    • If outputs get smaller as inputs get larger, the function is decreasing.
      🔗
      🔗
    • Intervals of increase and decrease are usually written using interval notation.
      🔗
      🔗
