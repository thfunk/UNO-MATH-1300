Example 1.3.17. A Graph That Continues Without Bound.

Use the graph to determine the domain and range. Express each answer using interval notation and inequality notation.
🔗
Solution.
The smallest input is \(-2\text{,}\) and it is included. The graph continues to the right without bound.
🔗
Domain in interval notation: \([-2,\infty)\)
🔗
Domain in inequality notation: \(x\ge -2\)
🔗
The smallest output is \(-4\text{,}\) and it is included. The graph continues upward without bound.
🔗
Range in interval notation: \([-4,\infty)\)
🔗
Range in inequality notation: \(y\ge -4\)
