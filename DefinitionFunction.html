    Section 1.2 Definition of a Function

    In this section, we will definine a function and learn how to identify the input and output variables of graphs, tables, diagrams, and equations.
    🔗

    Definition 1.2.1.

    A function is a relationship between two variables where every input corresponds to exactly one output.
    🔗
    🔗
    Depending on the situation, we may refer to the relationship between a function and its inputs and outputs as a mapping, a correspondence, or a rule. We also have several ways to represent functions. We can use a diagram, a table, a graph, or an equation.
    🔗

    Definition 1.2.2.

    The representation of a function \(y=f(x)\) is called function notation. The letter \(f\) is the name of the function, and the letter \(x\) is the input variable, and the letter \(y\) is the output variable. We say that \(y\) is a function of \(x\text{.}\)
    🔗
    🔗

    Subsection 1.2.1 Is it a Function - Diagrams

    Below, in Figure 1.2.4 and Figure 1.2.5 we have two examples of relationships which are functions. Notice that each input A, B, and C is mapped to exactly one output value. Two inputs can share the same output value, but each input must have a unique output value.
    🔗
    For example; in the first diagram, Figure 1.2.4, each input is going to a different output value. In the second diagram, Figure 1.2.5, inputs B and C are both going to the same output value of Pear, but each input is still going to a single output value.
    🔗
    Visually, a diagram which represents a function will always have a single arrow coming out of each input variable.
    🔗
    In contrast, the diagrams below are both examples of relationships that are not functions. There is an input which has two different outputs in each diagram.
    🔗
    In the first diagram, Figure 1.2.6, input B is going to both output values of Apple and Pear. In the second diagram, Figure 1.2.7, input A is going to both output values of Apple and Grape.
    🔗
    🔗

    Subsection 1.2.2 Is it a Function - Tables

    Recall that, in function notation, writing \(f(x) \) is the same as writing \(y \text{.}\) This is especially important when looking at a table as we often represent the output row/column with \(f(x) \) to give the reader the name of the function.
    🔗
    The top row of Table 1.2.8 gives all the input values (\(x\)-values), while the bottom row gives the output values (\(y\)-values). We know that this table is representing a function because each input is associated with a single output. This is seen by the fact that none of the \(x\)-values are repeated in the top row, and each cell in the bottom row has a single value listed. The fact that the output of \(3\) is achieved from multiple inputs is allowed in a function. This same function could have been represented as the table below.
    🔗
    While Table 1.2.9 looks different at a glance, notice that we now have the input variables in the first column and the output variables in the second column. Further, each input is being mapped to the same output as before, just in a different order.
    🔗
    Below in Table 1.2.10 we have an example of a table which is not a function.
    🔗
    We can identify this as not being a function due to having the input \(3\) listed multiple times, and is associated with a different output each time. We cannot have the input of \(3\) associated with both the output of \(7\) and \(9\text{.}\)
    🔗
    🔗

    Subsection 1.2.3 Is it a Function - Graphs

    In a graph we have the input variable located along the x-axis (the horizontal axis) and the output variable located along the y-axis (the vertical axis). Below are two examples of graphs representing functions.
    🔗
    We know that Figure 1.2.11 and Figure 1.2.12 are functions due to no \(x\)-value being associated with more than one output. Graphically, we often call this “passing the vertical line test”. This means that every vertical line you draw on the graphs of \(f(x)\) and \(g(x)\) will touch the representation of the function (the blue line) at most one time.
    🔗
    In the following two graphs we see relationships which do not represent a function. This is again best seen through the vertical line test. Note the red vertical line in each at \(x=1\) which intersects the relationship twice. This indicates that the input \(x=1\) is associated with multiple outputs making the relationship not a function. Thus, the relationships \(h(x)\) and \(j(x)\) are not functions.
    🔗
    🔗

    Subsection 1.2.4 Is it a Function - Equations

    Most equations we write will be examples of relationships which are functions. We would need to introduce piecewise functions in order to have a collection of examples of equations which are not functions. This will be a topic for later.
