    Section 3.5 Combining Transformations

    A function can undergo more than one transformation. To understand a combined transformation, separate the changes to inputs from the changes to outputs, and pay careful attention to the order in which operations are applied.
    🔗

    Objectives: Learning Objectives

    1. Describe multiple transformations represented by a function rule.
      🔗
      🔗
    2. Track a point through a sequence of transformations.
      🔗
      🔗
    3. Match a transformed graph with its equation.
      🔗
      🔗
    4. Explain why the order of transformations can affect the result.
      🔗
      🔗
    5. Connect combined transformations with composition of functions.
      🔗
      🔗
    🔗

    Subsection 3.5.1 Reading a Combined Transformation

    A useful general form is
    🔗
    \begin{equation*} g(x)=a f(b(x-c))+d. \end{equation*}
    The parameters describe transformations of the graph of \(f\text{:}\)
    🔗
    • \(x-c\) produces a horizontal shift.
      🔗
      🔗
    • The factor \(b\) produces horizontal scaling and, if negative, a reflection across the y-axis.
      🔗
      🔗
    • The factor \(a\) produces vertical scaling and, if negative, a reflection across the x-axis.
      🔗
      🔗
    • The value \(d\) produces a vertical shift.
      🔗
      🔗

    Example 3.5.1. Describing Several Transformations.

    Describe how the graph of \(f\) is transformed to obtain
    🔗
    \begin{equation*} g(x)=-2f(x+4)+3. \end{equation*}
    Solution.
    The expression \(x+4\) shifts the graph left 4 units.
    🔗
    The factor \(-2\) reflects the graph across the x-axis and stretches it vertically by a factor of 2.
    🔗
    The value \(+3\) shifts the graph up 3 units.
    🔗
    🔗
    🔗
    🔗

    Subsection 3.5.2 Moving a Point Through Several Transformations

    When transformations are given as a sequence, update the point after each step. Keeping a record of the intermediate coordinates helps prevent changes to inputs and outputs from being mixed together.
    🔗

    Example 3.5.2. Following a Sequence.

    The point \((-2,6)\) is on the graph of \(f\text{.}\) Find its final location after the graph is transformed in this order:
    🔗
    1. shift down 4 units,
      🔗
      🔗
    2. reflect across the y-axis,
      🔗
      🔗
    3. shift right 3 units,
      🔗
      🔗
    4. stretch vertically by a factor of 2.
      🔗
      🔗
    Solution.
    \begin{align*} (-2,6) &\longmapsto (-2,2) &\text{shift down 4}\\ &\longmapsto (2,2) &\text{reflect across the y-axis}\\ &\longmapsto (5,2) &\text{shift right 3}\\ &\longmapsto (5,4) &\text{vertical stretch by 2} \end{align*}
    The final point is \((5,4)\text{.}\)
    🔗
    🔗
    🔗

    Example 3.5.3. Using a Combined Rule.

    The point \((1,-3)\) is on the graph of \(f\text{.}\) Find the corresponding point on the graph of
    🔗
    \begin{equation*} h(x)=-3f(x-2)+5. \end{equation*}
    Solution.
    The expression \(x-2\) shifts the input location right 2 units, so the new x-coordinate is \(1+2=3\text{.}\)
    🔗
    The output is multiplied by \(-3\) and then increased by 5:
    🔗
    \begin{equation*} -3(-3)+5=14. \end{equation*}
    The corresponding point is \((3,14)\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 3.5.3 Order Matters

    Two transformations that affect the same coordinate may produce different results when their order is reversed.
    🔗

    Example 3.5.4. Shift Then Scale, or Scale Then Shift?

    The point \((-3,2)\) is on the graph of \(f\text{.}\) Compare the final point in each sequence.
    🔗
    1. First shift up 4 units, then stretch vertically by a factor of 3.
      🔗
      🔗
    2. First stretch vertically by a factor of 3, then shift up 4 units.
      🔗
      🔗
    Solution.
    1. The output changes from \(2\) to \(6\text{,}\) then to \(18\text{.}\) The final point is \((-3,18)\text{.}\)
      🔗
      🔗
    2. The output changes from \(2\) to \(6\text{,}\) then to \(10\text{.}\) The final point is \((-3,10)\text{.}\)
      🔗
      🔗
    The results differ because \(3(f(x)+4)=3f(x)+12\text{,}\) while applying the stretch first and then shifting gives \(3f(x)+4\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 3.5.4 Matching Graphs and Equations

    Example 3.5.5. Use More Than One Anchor Point.

    Match each graph described above with one of the following equations:
    🔗
    1. \(\displaystyle f(x)-2\)
      🔗
      🔗
    2. \(\displaystyle 2f(x)\)
      🔗
      🔗
    3. \(\displaystyle f(x+3)\)
      🔗
      🔗
    Solution.
    The graph of \(f(x)-2\) has the same x-coordinates as \(f\text{,}\) but every output is 2 smaller.
    🔗
    The graph of \(2f(x)\) has the same x-coordinates and x-intercepts as \(f\text{,}\) but every output is doubled.
    🔗
    The graph of \(f(x+3)\) has the same shape and output values as \(f\text{,}\) but every point is shifted left 3 units.
    🔗
    Checking multiple anchor points helps distinguish a shift from a scaling.
    🔗
    🔗
    🔗
    🔗

    Subsection 3.5.5 Transformations as Compositions

    Transformations can be represented by composing simple functions. The order of the composition records which transformation happens first.
    🔗

    Example 3.5.6. Comparing Two Compositions.

    Let \(F(x)=x^2\) and \(S(x)=x-6\text{.}\) Find \(F(S(x))\) and \(S(F(x))\text{,}\) and describe the transformation of the parent graph \(y=x^2\) in each case.
    🔗
    Solution.
    For the first composition, substitute \(x-6\) into \(F\text{:}\)
    🔗
    \begin{equation*} F(S(x))=(x-6)^2. \end{equation*}
    This shifts the graph of \(y=x^2\) right 6 units.
    🔗
    For the second composition, substitute \(x^2\) into \(S\text{:}\)
    🔗
    \begin{equation*} S(F(x))=x^2-6. \end{equation*}
    This shifts the graph of \(y=x^2\) down 6 units.
    🔗
    The compositions produce different transformations because the order of the functions is different.
    🔗
    🔗
    🔗

    Example 3.5.7. Building a Combined Transformation with Composition.

    Let \(R(x)=x+1\text{,}\) \(V(x)=-2x\text{,}\) and \(p(x)=x^3\text{.}\) Find
    🔗
    \begin{equation*} g(x)=R(V(p(R(x)))) \end{equation*}
    and explain how the composition transforms the graph of \(p(x)=x^3\text{.}\)
    🔗
    Solution.
    Work from the inside out:
    🔗
    \begin{align*} R(x)&=x+1,\\ p(R(x))&=(x+1)^3,\\ V(p(R(x)))&=-2(x+1)^3,\\ R(V(p(R(x))))&=-2(x+1)^3+1. \end{align*}
    Relative to \(p(x)=x^3\text{,}\) the graph shifts left 1 unit, reflects across the x-axis, stretches vertically by a factor of 2, and shifts up 1 unit.
    🔗
    🔗
    🔗
    🔗

    Subsection 3.5.6 Key Ideas

    • Separate changes to inputs from changes to outputs.
      🔗
      🔗
    • Track intermediate points when transformations are listed in sequence.
      🔗
      🔗
    • Order matters when multiple operations affect the same coordinate.
      🔗
      🔗
    • Use several anchor points when matching a transformed graph to an equation.
      🔗
      🔗
    • A composition records transformation order from the inside function to the outside function.
      🔗
      🔗
