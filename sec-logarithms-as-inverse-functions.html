    Section 5.3 Logarithms as Inverse Functions

    An exponential function answers the question, “What output results from this exponent?” A logarithmic function reverses that process by answering, “What exponent produces this output?” In this section, we define logarithms as inverse functions, evaluate logarithms, and use logarithms to find unknown exponents.
    🔗

    Objectives: Learning Objectives

    1. Interpret a logarithm as an exponent.
      🔗
      🔗
    2. Convert between exponential form and logarithmic form.
      🔗
      🔗
    3. Explain why exponential and logarithmic functions are inverses.
      🔗
      🔗
    4. Evaluate logarithms exactly and approximately.
      🔗
      🔗
    5. Use logarithms to solve exponential equations.
      🔗
      🔗
    🔗

    Subsection 5.3.1 Reversing an Exponential Process

    Example 5.3.1. How Long Until the Lake Reaches a Given Size?

    Let \(L=f(d)=5(2)^d\) represent the number of floating plants in a pond after \(d\) days.
    🔗
    1. What are the input and output of \(f\text{?}\)
      🔗
      🔗
    2. What question does \(f^{-1}(160)\) answer?
      🔗
      🔗
    Solution.
    1. The input is time in days, and the output is the number of floating plants.
      🔗
      🔗
    2. The inverse uses a number of plants as its input and returns the corresponding number of days. Thus, \(f^{-1}(160)\) asks how many days it takes the pond to reach 160 plants.
      🔗
      🔗
    🔗
    🔗

    Remark 5.3.2.

    The entire range of the exponential function becomes the domain of its inverse. The units switch along with the numerical values.
    🔗
    🔗
    🔗

    Subsection 5.3.2 Defining a Logarithm

    Definition 5.3.3. Logarithm.

    For \(b>0\text{,}\) \(b\ne1\text{,}\) and \(x>0\text{,}\)
    🔗
    \begin{equation*} y=\log_b(x) \end{equation*}
    if and only if
    🔗
    \begin{equation*} b^y=x. \end{equation*}
    The value of a logarithm is an exponent.
    🔗
    🔗

    Example 5.3.4. Reading a Logarithm as an Exponent.

    Evaluate \(\log_3(81)\text{.}\)
    🔗
    Solution.
    The question asks, “What exponent on 3 produces 81?” Since \(3^4=81\text{,}\)
    🔗
    \begin{equation*} \log_3(81)=4. \end{equation*}
    🔗
    🔗

    Example 5.3.5. A Negative Logarithm Value.

    Evaluate \(\log_5\left(\frac{1}{125}\right)\text{.}\)
    🔗
    Solution.
    Since \(5^{-3}=\frac{1}{125}\text{,}\)
    🔗
    \begin{equation*} \log_5\left(\frac{1}{125}\right)=-3. \end{equation*}
    🔗
    🔗

    Example 5.3.6. Converting Between Forms.

    1. Rewrite \(7^2=49\) in logarithmic form.
      🔗
      🔗
    2. Rewrite \(\log_4(64)=3\) in exponential form.
      🔗
      🔗
    Solution.
    1. \(\log_7(49)=2\text{.}\)
      🔗
      🔗
    2. \(4^3=64\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Subsection 5.3.3 Exponential and Logarithmic Functions Are Inverses

    For a fixed base \(b\text{,}\) the exponential function \(f(x)=b^x\) and the logarithmic function \(f^{-1}(x)=\log_b(x)\) reverse one another.
    🔗
    \begin{equation*} \log_b\left(b^x\right)=x \end{equation*}
    \begin{equation*} b^{\log_b(x)}=x \end{equation*}

    Example 5.3.7. Switching Inputs and Outputs.

    Let \(f(x)=4^x\text{.}\)
    🔗
    1. Evaluate \(f(3)\text{.}\)
      🔗
      🔗
    2. Use the inverse relationship to evaluate \(f^{-1}(64)\text{.}\)
      🔗
      🔗
    3. Write a formula for \(f^{-1}\text{.}\)
      🔗
      🔗
    Solution.
    1. \(f(3)=4^3=64\text{.}\)
      🔗
      🔗
    2. Because the inverse switches the input and output, \(f^{-1}(64)=3\text{.}\)
      🔗
      🔗
    3. \(f^{-1}(x)=\log_4(x)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Subsection 5.3.4 Common and Natural Logarithms

    Definition 5.3.8. Common Logarithm.

    The common logarithm has base 10. When no base is written,
    🔗
    \begin{equation*} \log(x)=\log_{10}(x). \end{equation*}
    🔗

    Definition 5.3.9. Natural Logarithm.

    The natural logarithm has base \(e\text{:}\)
    🔗
    \begin{equation*} \ln(x)=\log_e(x). \end{equation*}
    🔗

    Example 5.3.10. Exact and Approximate Values.

    1. Evaluate \(\log(10000)\) exactly.
      🔗
      🔗
    2. Evaluate \(\ln(e^{-2})\) exactly.
      🔗
      🔗
    3. Approximate \(\ln(23)\) to three decimal places.
      🔗
      🔗
    Solution.
    1. Because \(10^4=10000\text{,}\) \(\log(10000)=4\text{.}\)
      🔗
      🔗
    2. Because natural logarithms and powers of \(e\) are inverse operations, \(\ln(e^{-2})=-2\text{.}\)
      🔗
      🔗
    3. Using a calculator, \(\ln(23)\approx3.135\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Subsection 5.3.5 Properties of Logarithms

    The properties of logarithms follow from the corresponding rules for exponents.
    🔗

    Definition 5.3.11. Basic Properties.

    When all expressions are defined,
    🔗
    \begin{align*} \log_b(AC)&=\log_b(A)+\log_b(C),\\ \log_b\left(\frac{A}{C}\right)&=\log_b(A)-\log_b(C),\\ \log_b(A^r)&=r\log_b(A). \end{align*}
    🔗

    Example 5.3.12. Using Logarithm Properties.

    Expand \(\log_3\left(\frac{x^4y}{z} ight)\text{.}\)
    🔗
    Solution.
    \begin{align*} \log_3\left(\frac{x^4y}{z}\right)&=\log_3(x^4y)-\log_3(z)\\ &=\log_3(x^4)+\log_3(y)-\log_3(z)\\ &=4\log_3(x)+\log_3(y)-\log_3(z). \end{align*}
    🔗
    🔗
    🔗

    Subsection 5.3.6 Solving Exponential Equations with Logarithms

    When an exponential equation cannot be rewritten with a convenient common base, apply a logarithm to both sides and use the power property to move the exponent in front.
    🔗

    Example 5.3.13. Finding an Unknown Exponent.

    Solve \(5(2)^t=140\text{.}\)
    🔗
    Solution.
    First isolate the exponential term:
    🔗
    \begin{equation*} 2^t=28. \end{equation*}
    Apply the natural logarithm to both sides:
    🔗
    \begin{align*} \ln(2^t)&=\ln(28),\\ t\ln(2)&=\ln(28),\\ t&=\frac{\ln(28)}{\ln(2)}\approx4.807. \end{align*}
    🔗
    🔗

    Example 5.3.14. Finding the Inverse of an Exponential Function.

    Find the inverse of \(f(x)=6(3)^x-4\text{.}\)
    🔗
    Solution.
    Write \(y=6(3)^x-4\text{,}\) switch \(x\) and \(y\text{,}\) and isolate the exponential expression:
    🔗
    \begin{align*} x&=6(3)^y-4,\\ x+4&=6(3)^y,\\ \frac{x+4}{6}&=3^y. \end{align*}
    Apply a logarithm:
    🔗
    \begin{align*} \ln\left(\frac{x+4}{6}\right)&=\ln(3^y),\\ \ln\left(\frac{x+4}{6}\right)&=y\ln(3),\\ y&=\frac{\ln\left((x+4)/6\right)}{\ln(3)}. \end{align*}
    Therefore,
    🔗
    \begin{equation*} f^{-1}(x)=\frac{\ln\left((x+4)/6\right)}{\ln(3)}. \end{equation*}
    🔗
    🔗
    🔗
    A logarithm is an exponent, and logarithmic functions reverse exponential functions. The equivalence \(y=\log_b(x)\) if and only if \(b^y=x\) allows us to convert between forms, evaluate logarithms, and solve equations in which the unknown appears in an exponent.
