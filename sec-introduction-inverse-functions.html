    Section 5.1 Introduction to Inverse Functions

    Many processes can be reversed. An inverse function reverses the action of another function by exchanging its inputs and outputs. In this section, we use processes, tables, and graphs to develop the idea of an inverse function.
    🔗

    Objectives: Learning Objectives

    1. Explain an inverse function as a process that undoes another function.
      🔗
      🔗
    2. Construct an inverse relation by switching inputs and outputs in a table.
      🔗
      🔗
    3. Determine whether the inverse relation is also a function.
      🔗
      🔗
    4. Construct the graph of an inverse by switching the coordinates of points.
      🔗
      🔗
    5. Relate the domain and range of a function to those of its inverse.
      🔗
      🔗
    🔗

    Subsection 5.1.1 Inverses as Undoing

    An inverse reverses a process. If a process changes an original object into a new object, the inverse begins with the new object and reverses the steps to recover the original object.
    🔗

    Example 5.1.1. Reversing a Paper-Folding Process.

    Suppose a function \(F\) takes a square sheet of paper as its input and applies a fixed sequence of folds to make an origami animal. Describe what the inverse process \(F^{-1}\) would do.
    🔗
    Solution.
    The inverse process begins with the finished origami animal and reverses the folding steps in the opposite order. Its output is the original square sheet of paper.
    🔗
    The input of \(F\) becomes the output of \(F^{-1}\text{,}\) and the output of \(F\) becomes the input of \(F^{-1}\text{.}\)
    🔗
    🔗
    🔗

    Example 5.1.2. An Everyday Reversible Process.

    A machine converts a temperature from degrees Celsius to degrees Fahrenheit. What would its inverse machine do?
    🔗
    Solution.
    The original process accepts a Celsius temperature and outputs a Fahrenheit temperature. The inverse accepts a Fahrenheit temperature and outputs the corresponding Celsius temperature.
    🔗
    🔗
    🔗

    Remark 5.1.3.

    Not every process can be reversed uniquely. If information is lost in the original process, the output may not determine one original input.
    🔗
    🔗
    🔗

    Subsection 5.1.2 Definition of an Inverse Function

    Definition 5.1.4. Inverse Function.

    An inverse function, written \(f^{-1}\text{,}\) reverses the input-output relationship of a function \(f\text{.}\) If \(f(a)=b\text{,}\) then \(f^{-1}(b)=a\text{.}\)
    🔗
    🔗
    • The input of \(f\) becomes the output of \(f^{-1}\text{.}\)
      🔗
      🔗
    • The output of \(f\) becomes the input of \(f^{-1}\text{.}\)
      🔗
      🔗
    • The domain of \(f\) becomes the range of \(f^{-1}\text{.}\)
      🔗
      🔗
    • The range of \(f\) becomes the domain of \(f^{-1}\text{.}\)
      🔗
      🔗

    Warning 5.1.5.

    The notation \(f^{-1}(x)\) means the inverse function. It does not mean \(1/f(x)\text{.}\)
    🔗
    🔗
    🔗

    Subsection 5.1.3 Inverses from Tables

    To create a table for an inverse, switch the input and output in every row.
    🔗

    Example 5.1.6. Switching Inputs and Outputs.

    The function \(g\) is represented by the table. Construct a table for \(g^{-1}\text{.}\)
    🔗
    Solution.
    Switch the entries in each input-output pair.
    🔗
    For example, \(g(-1)=2\) becomes \(g^{-1}(2)=-1\text{.}\)
    🔗
    🔗
    🔗

    Example 5.1.9. When the Inverse Relation Is Not a Function.

    Determine whether the inverse relation of the function below is also a function.
    🔗
    Solution.
    The output 6 is paired with both inputs 1 and 3. After switching inputs and outputs, the input 6 would have two outputs, 1 and 3.
    🔗
    Therefore, the inverse relation is not a function, so \(h\) does not have an inverse function on this domain.
    🔗
    🔗
    🔗

    Definition 5.1.11. One-to-One Function.

    A function is one-to-one if different inputs always produce different outputs. A function has an inverse function precisely when it is one-to-one on its domain.
    🔗
    🔗
    🔗

    Subsection 5.1.4 Inverses from Graphs

    Switching the coordinates of every point transforms the graph of a function into the graph of its inverse. A point \((a,b)\) on the graph of \(f\) becomes \((b,a)\) on the graph of \(f^{-1}\text{.}\)
    🔗

    Example 5.1.12. Which Graph Has an Inverse Function?

    Use the two graphs described above to determine which function has an inverse function.
    🔗
    Solution.
    The strictly increasing graph has an inverse function because every output belongs to only one input.
    🔗
    The parabola does not have an inverse function on its full domain because some outputs belong to two different inputs.
    🔗
    🔗
    🔗

    Definition 5.1.13. Horizontal Line Test.

    A function has an inverse function if every horizontal line intersects its graph at most once.
    🔗
    🔗

    Example 5.1.14. Constructing an Inverse Graph from Points.

    A one-to-one function passes through \((-2,1)\text{,}\) \((0,3)\text{,}\) \((2,4)\text{,}\) and \((5,7)\text{.}\) List points on its inverse and describe how to graph the inverse.
    🔗
    Solution.
    Switch the coordinates of each ordered pair:
    🔗
    \begin{align*} (-2,1)&\longrightarrow(1,-2),\\ (0,3)&\longrightarrow(3,0),\\ (2,4)&\longrightarrow(4,2),\\ (5,7)&\longrightarrow(7,5). \end{align*}
    Plot the switched points and connect them in the corresponding order. The original graph and inverse graph are reflections of each other across the line \(y=x\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 5.1.5 Evaluating Inverse Notation

    Example 5.1.15. Reading an Inverse Value.

    Use Table 5.1.7 to find \(g^{-1}(5)\text{.}\)
    🔗
    Solution.
    The statement asks which input of \(g\) produces the output 5. The table shows \(g(4)=5\text{,}\) so
    🔗
    \begin{equation*} g^{-1}(5)=4. \end{equation*}
    🔗
    🔗
    🔗

    Subsection 5.1.6 Key Ideas

    • An inverse reverses a function by switching its inputs and outputs.
      🔗
      🔗
    • If \(f(a)=b\text{,}\) then \(f^{-1}(b)=a\text{.}\)
      🔗
      🔗
    • The domain and range exchange roles.
      🔗
      🔗
    • Only one-to-one functions have inverse functions.
      🔗
      🔗
    • Inverse graphs are reflections across the line \(y=x\text{.}\)
      🔗
      🔗
    🔗
