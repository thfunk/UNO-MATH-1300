    Section 5.5 Applications of Logarithms

    In many exponential models, the input is time and the output is a changing quantity. A logarithm, or equivalently the inverse of the exponential model, allows us to reverse the question: given an output, when does it occur? In this section, we interpret inverse functions in context and use logarithms to solve applied problems.
    🔗

    Objectives: Learning Objectives

    1. Identify the input, output, and units of an exponential model and its inverse.
      🔗
      🔗
    2. Interpret inverse-function notation in context.
      🔗
      🔗
    3. Use logarithms to solve for an unknown input in an exponential model.
      🔗
      🔗
    4. Write an inverse formula for a shifted exponential function.
      🔗
      🔗
    5. Interpret exact and approximate solutions appropriately.
      🔗
      🔗
    🔗

    Subsection 5.5.1 Forward and Inverse Questions

    A forward exponential model begins with an input and calculates an output. Its inverse begins with an output and determines the input that produced it.
    🔗

    Example 5.5.1. Heating a Greenhouse.

    The temperature of a greenhouse is modeled by
    🔗
    \begin{equation*} T=h(t)=72-24(0.91)^t, \end{equation*}
    where \(t\) is the number of minutes after the heater is turned on and \(T\) is the temperature in degrees Fahrenheit.
    🔗
    1. Identify the input and output of \(h\text{.}\)
      🔗
      🔗
    2. Identify the input and output of \(h^{-1}\text{.}\)
      🔗
      🔗
    3. Interpret \(h^{-1}(60)=7.31\text{.}\)
      🔗
      🔗
    Solution.
    1. The input of \(h\) is time in minutes. The output is temperature in degrees Fahrenheit.
      🔗
      🔗
    2. The input of \(h^{-1}\) is temperature in degrees Fahrenheit. The output is time in minutes.
      🔗
      🔗
    3. The greenhouse reaches 60 degrees Fahrenheit about 7.31 minutes after the heater is turned on.
      🔗
      🔗
    🔗
    🔗
    When a function and its inverse are interpreted in context, the numerical values switch roles and the units switch roles as well.
    🔗
    🔗

    Subsection 5.5.2 Solving for Time with Logarithms

    1. Substitute the known output into the model.
      🔗
      🔗
    2. Isolate the exponential expression.
      🔗
      🔗
    3. Apply a logarithm to both sides.
      🔗
      🔗
    4. Use the power property and solve for the input.
      🔗
      🔗
    5. Interpret the solution with units and appropriate rounding.

    Example 5.5.2. When Does the Greenhouse Reach a Target Temperature?

    Using \(T=h(t)=72-24(0.91)^t\text{,}\) determine when the greenhouse reaches 65 degrees Fahrenheit.
    🔗
    Solution.
    Substitute the target temperature and isolate the exponential expression:
    🔗
    \begin{align*} 65&=72-24(0.91)^t,\\ -7&=-24(0.91)^t,\\ \frac{7}{24}&=(0.91)^t. \end{align*}
    Apply the natural logarithm:
    🔗
    \begin{align*} \ln\left(\frac{7}{24}\right)&=\ln\left((0.91)^t\right),\\ \ln\left(\frac{7}{24}\right)&=t\ln(0.91),\\ t&=\frac{\ln(7/24)}{\ln(0.91)}\approx13.069. \end{align*}
    The greenhouse reaches 65 degrees Fahrenheit about 13.1 minutes after the heater is turned on.
    🔗
    🔗
    🔗

    Example 5.5.3. Medicine Remaining in the Body.

    The amount of a medicine in a person’s body is modeled by
    🔗
    \begin{equation*} M(t)=180e^{-0.16t}, \end{equation*}
    where \(t\) is measured in hours and \(M(t)\) is measured in milligrams. When will 50 milligrams remain?
    🔗
    Solution.
    \begin{align*} 50&=180e^{-0.16t},\\ \frac{5}{18}&=e^{-0.16t},\\ \ln\left(\frac{5}{18}\right)&=-0.16t,\\ t&=\frac{\ln(5/18)}{-0.16}\approx8.008. \end{align*}
    About 8.0 hours after the medicine is administered, 50 milligrams remain.
    🔗
    🔗
    🔗

    Example 5.5.4. Reaching a Membership Goal.

    A community program starts with 320 members, and membership grows by 6% each month. The model is
    🔗
    \begin{equation*} N(t)=320(1.06)^t. \end{equation*}
    How many months will it take for membership to reach 500?
    🔗
    Solution.
    \begin{align*} 500&=320(1.06)^t,\\ \frac{25}{16}&=(1.06)^t,\\ t&=\frac{\ln(25/16)}{\ln(1.06)}\approx7.660. \end{align*}
    The model reaches 500 members after about 7.66 months. If membership is recorded only at the end of each month, the program first has at least 500 members during month 8.
    🔗
    🔗
    🔗

    Subsection 5.5.3 Writing an Inverse Model

    Finding a formula for the inverse is helpful when many different output values will be used to determine corresponding inputs.
    🔗

    Example 5.5.5. Finding the Inverse of a Shifted Exponential Model.

    Find a formula for the inverse of
    🔗
    \begin{equation*} T=h(t)=72-24(0.91)^t. \end{equation*}
    Solution.
    Switch the input and output variables, then solve for the new output:
    🔗
    \begin{align*} x&=72-24(0.91)^y,\\ 72-x&=24(0.91)^y,\\ \frac{72-x}{24}&=(0.91)^y. \end{align*}
    Apply the natural logarithm:
    🔗
    \begin{align*} \ln\left(\frac{72-x}{24}\right)&=y\ln(0.91),\\ y&=\frac{\ln\left((72-x)/24\right)}{\ln(0.91)}. \end{align*}
    Therefore,
    🔗
    \begin{equation*} h^{-1}(x)=\frac{\ln\left((72-x)/24\right)}{\ln(0.91)}. \end{equation*}
    In context, the input of \(h^{-1}\) is a temperature and the output is the number of minutes needed to reach that temperature.
    🔗
    🔗
    🔗
    🔗

    Subsection 5.5.4 Analyzing Common Errors

    Example 5.5.6. Finding the First Incorrect Step.

    A student attempts to solve \(8(1.25)^t-12=68\text{:}\)
    🔗
    \begin{align*} 8(1.25)^t&=80,\\ (1.25)^t&=10,\\ t\ln(8(1.25))&=\ln(80),\\ t&=\frac{\ln(80)}{\ln(10)}. \end{align*}
    Identify the first incorrect step and give the correct solution.
    🔗
    Solution.
    The first two steps are correct. The third step incorrectly places the coefficient 8 inside the logarithmic factor after the exponential expression has already been isolated.
    🔗
    Starting from \((1.25)^t=10\text{,}\) the correct work is
    🔗
    \begin{align*} \ln\left((1.25)^t\right)&=\ln(10),\\ t\ln(1.25)&=\ln(10),\\ t&=\frac{\ln(10)}{\ln(1.25)}\approx10.319. \end{align*}
    🔗
    🔗

    Warning 5.5.7.

    Do not distribute a logarithm across addition or subtraction. In general, \(\ln(A+B)\ne\ln(A)+\ln(B)\text{.}\) Isolate the exponential expression before applying a logarithm.
    🔗
    🔗
    🔗

    Subsection 5.5.5 Key Ideas

    • A forward exponential model uses an input to calculate an output.
      🔗
      🔗
    • The inverse model uses an output to determine the input that produced it.
      🔗
      🔗
    • Inputs, outputs, and units switch roles in an inverse function.
      🔗
      🔗
    • Isolate the exponential expression before applying a logarithm.
      🔗
      🔗
    • Interpret the final solution in context and include appropriate units.
      🔗
      🔗
    🔗
    Logarithms make it possible to answer inverse questions in exponential contexts. When an output is known and the input is unknown, isolate the exponential expression, apply a logarithm, solve, and interpret the result with its units. An inverse formula packages this process into a reusable function.
